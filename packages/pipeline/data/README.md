# pipeline/data

- `sourceCatalogMatch.json` -- generated by `pnpm --filter @amigurumi/pipeline run match:catalog`.
  Fuzzy-matches thewoobles.com's Shopify product feed to catalog patterns by
  name and records `{productUrl, imageUrl}` per pattern. `buildCatalog.ts`
  merges this file (if present) into `patterns.json`; it is safe to delete or
  regenerate at any time and the build falls back to `null` image/purchase
  URLs if it's missing.

  thewoobles.com's edge rate-limits repeated automated requests, so this
  usually needs to be run from the `match-catalog.yml` GitHub Actions
  workflow (`workflow_dispatch`) rather than a local dev sandbox -- see that
  workflow for details.

- `sourceCatalogOverrides.json` -- hand-maintained. Ambiguous or wrong
  auto-matches show up in `sourceCatalogMatch.json`'s `ambiguous`/`unmatched`
  lists; add an entry here (`{"<patternId>": {"productHandle": "<shopify-handle>"}}`)
  to force the correct match on the next run.
